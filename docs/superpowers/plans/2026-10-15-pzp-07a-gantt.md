# PZP-07a — План-график цеха: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Страница «Планирование → План-график цеха»: неинтерактивный Гантт загрузки ТПА с парами баров план/факт, прогнозом окончания выпуска, остатком буфера и перерасходом; плюс доступ Observer к «Планированию» только на чтение.

**Architecture:** Расчёт бара — чистая функция `PlanningBoardCalculator` в Core поверх `TaskPlanCalculator` и `ReleaseForecast`; входы прогноза собирает новый `IReleaseForecastService` (общий для плитки ТПА и Гантта). Эндпоинт `GET /api/planning/board?from&to` отдаёт строки ТПА с готовыми сегментами. Фронт рисует Гантт на HTML/CSS (по образцу `ShiftTimeline`, BL-40); вся геометрия — в чистом `utils/planningBoard.js`.

**Tech Stack:** ASP.NET Core 9, EF Core 9 + Npgsql, xUnit + FluentAssertions; Vue 3, Element Plus, Pinia, Vitest + @vue/test-utils (jsdom).

**Спека:** `docs/superpowers/specs/2026-10-15-pzp-07a-gantt-design.md`.

## Global Constraints

- Эндпоинт: `GET /api/planning/board?from=<UTC>&to=<UTC>`, роли Admin/Manager/Observer; `to > from`, длина окна ≤ **62** суток, иначе 400.
- Все `DateTime` в EF-запросах — `Kind=Utc` (правило CLAUDE.md).
- План задания не хранится; гнёзда — текущие `Mold.Cavities`; прогноз — `ReleaseForecast` (ADR-0017), только `InProgress`.
- Для `Setup` прогноз и остаток буфера **не считаются**; текст «наладка отстала на X», если `now > plannedStartAt + plannedSetupMinutes`.
- Просроченное неначатое (`Planned`/`Issued`, плановое начало прошло) — план-бар на месте + красная метка «не начато, опоздание N».
- Остаток буфера `= P − окончание выпуска` (`P` = `PlannedEndAt`; окончание — прогноз для `InProgress`, `CompletedAt ?? ClosedAt` для завершённых); `< 0` — красный сегмент «перерасход».
- Масштаб по умолчанию — неделя; «Сутки» — от начала первой смены, «Неделя» — с понедельника 00:00, «Месяц» — с 1-го 00:00 (пояс браузера). Обновление — раз в 60 с.
- Строки — активные ТПА по названию + архивные с заданиями в окне (пометка «в архиве»).
- Подпись план-бара: «артикул · ПФ · план шт». Тултип — нативный `title` (как в `ShiftTimeline`).
- Observer: только чтение; запись защищена на бэкенде. Меню «Администрирование» — только Admin (не трогаем).
- Время на экране — в поясе браузера; на сервер — ISO UTC.
- Коммиты заканчиваются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

using TaskStatus = Wintime.Control.Core.Enums.TaskStatus;

namespace Wintime.Control.Core.Policies;

/// <summary>Плановые границы бара задания, UTC: наладка → выпуск → буфер. <c>null</c> — выпуск не посчитать.</summary>
public sealed record BoardPlan(DateTime SetupStart, DateTime SetupEnd, DateTime? ReleaseEnd, DateTime? BufferEnd);

/// <summary>Фактические границы бара, UTC; <c>ForecastEnd</c> — прогноз окончания выпуска (только InProgress).</summary>
public sealed record BoardFact(DateTime? SetupStart, DateTime? SetupEnd, DateTime? ReleaseEnd, DateTime? ForecastEnd);

/// <summary>Статус и метки задания, нужные бару.</summary>
public sealed record BoardTaskFacts(TaskStatus Status, DateTime? SetupStartedAt, DateTime? StartedAt,
                                    DateTime? CompletedAt, DateTime? ClosedAt);

/// <summary>
/// Бар задания на Гантте. <c>BufferRemainingSeconds</c> &lt; 0 — перерасход сверх буфера;
/// <c>OverdueNotStartedSeconds</c> — просрочка неначатого; <c>SetupLagSeconds</c> — отставание наладки.
/// </summary>
public sealed record BoardTiming(BoardPlan Plan, BoardFact Fact, long? BufferRemainingSeconds,
                                 long? OverdueNotStartedSeconds, long? SetupLagSeconds);

/// <summary>
/// План-график цеха (PZP-07a): план и факт задания для пары баров. Чистая функция, не хранится.
/// Остаток буфера = плановое окончание (с буфером) − окончание выпуска: прогноз для InProgress,
/// факт для завершённых. Для Setup прогноз и остаток не считаются — только отставание наладки.
/// </summary>
public static class PlanningBoardCalculator
{
    public static BoardTiming Build(DateTime plannedStartUtc, TaskPlan plan, BoardTaskFacts facts,
                                    ReleaseForecastResult? forecast, DateTime nowUtc)
    {
        var setupEnd = plannedStartUtc.AddSeconds(plan.SetupSeconds);
        DateTime? bufferEnd = plan.PlannedEndAt;
        DateTime? releaseEnd = bufferEnd is DateTime b && plan.BufferSeconds is long buffer
            ? b.AddSeconds(-buffer)
            : null;
        var planBar = new BoardPlan(plannedStartUtc, setupEnd, releaseEnd, bufferEnd);

        var finishedAt = facts.CompletedAt ?? facts.ClosedAt;
        // Закрыто во время наладки — наладка кончилась закрытием, выпуска не было.
        DateTime? factSetupEnd = facts.StartedAt ?? (facts.SetupStartedAt != null ? finishedAt : null);
        DateTime? factReleaseEnd = facts.StartedAt != null ? finishedAt : null;
        DateTime? forecastEnd = facts.Status == TaskStatus.InProgress ? ForecastEnd(forecast, nowUtc) : null;
        var factBar = new BoardFact(facts.SetupStartedAt, factSetupEnd, factReleaseEnd, forecastEnd);

        DateTime? releaseFinish = facts.Status == TaskStatus.InProgress ? forecastEnd
            : facts.Status is TaskStatus.Completed or TaskStatus.Closed ? factReleaseEnd
            : null;
        long? remaining = bufferEnd is DateTime p && releaseFinish is DateTime e ? Seconds(p - e) : null;

        long? overdue = facts.Status is TaskStatus.Planned or TaskStatus.Issued && nowUtc > plannedStartUtc
            ? Seconds(nowUtc - plannedStartUtc)
            : null;
        long? lag = facts.Status == TaskStatus.Setup && nowUtc > setupEnd ? Seconds(nowUtc - setupEnd) : null;

        return new BoardTiming(planBar, factBar, remaining, overdue, lag);
    }

    /// <summary>
    /// Плановое окно <c>[SetupStart, BufferEnd ?? SetupEnd)</c> пересекает <c>[fromUtc, toUtc)</c>.
    /// Окно нулевой длины — точка: попадает, если лежит в <c>[fromUtc, toUtc)</c>.
    /// </summary>
    public static bool PlanOverlaps(BoardPlan plan, DateTime fromUtc, DateTime toUtc)
    {
        var end = plan.BufferEnd ?? plan.SetupEnd;
        return plan.SetupStart < toUtc && (end > fromUtc || plan.SetupStart >= fromUtc);
    }

    // План выполнен (темп есть, прогноза нет) — выпуск кончается «сейчас»; темпа нет — не посчитать.
    private static DateTime? ForecastEnd(ReleaseForecastResult? forecast, DateTime nowUtc) =>
        forecast is null ? null : forecast.ForecastAt ?? (forecast.RatePerHour != null ? nowUtc : null);

    private static long Seconds(TimeSpan span) => (long)Math.Floor(span.TotalSeconds);
}

using Microsoft.EntityFrameworkCore;
using Wintime.Control.Core.Interfaces;
using Wintime.Control.Core.Policies;
using Wintime.Control.Infrastructure.Data;
using TaskStatus = Wintime.Control.Core.Enums.TaskStatus;

namespace Wintime.Control.Infrastructure.Services;

public class ReleaseForecastService : IReleaseForecastService
{
    private readonly ControlDbContext _context;

    public ReleaseForecastService(ControlDbContext context) => _context = context;

    public async Task<IReadOnlyDictionary<Guid, ReleaseForecastResult>> CalculateAsync(
        IReadOnlyCollection<Guid> taskIds, DateTime nowUtc, CancellationToken ct = default)
    {
        if (taskIds.Count == 0)
            return new Dictionary<Guid, ReleaseForecastResult>();

        var ids = taskIds.ToList();
        var inputs = await _context.ShiftTasks
            .Where(t => ids.Contains(t.Id) && t.Status == TaskStatus.InProgress)
            .Select(t => new { t.Id, t.PlanQuantity, t.ActualQuantity, t.PlannedFullCycleSeconds, t.Mold.Cavities })
            .ToListAsync(ct);
        if (inputs.Count == 0)
            return new Dictionary<Guid, ReleaseForecastResult>();

        var inProgressIds = inputs.Select(i => i.Id).ToList();
        // Открытые циклы (EndTime = null) в среднее не входят; null-паузы (наладка, простой, порог)
        // AVG пропускает — ADR-0017.
        var stats = await _context.ImmCycles
            .Where(c => c.TaskId.HasValue && inProgressIds.Contains(c.TaskId.Value) && c.EndTime != null)
            .GroupBy(c => c.TaskId!.Value)
            .Select(g => new
            {
                TaskId = g.Key,
                Closed = g.Count(),
                AvgDuration = g.Average(c => (double?)c.DurationSeconds) ?? 0,
                AvgPauseMs = g.Average(c => (double?)c.PauseDurationMs)
            })
            .ToDictionaryAsync(s => s.TaskId, ct);

        return inputs.ToDictionary(i => i.Id, i =>
        {
            stats.TryGetValue(i.Id, out var s);
            return ReleaseForecast.Calculate(nowUtc, i.PlanQuantity, i.ActualQuantity, i.Cavities,
                s?.Closed ?? 0, s?.AvgDuration ?? 0, s?.AvgPauseMs, i.PlannedFullCycleSeconds);
        });
    }
}

public class PlanningController : ControllerBase

    /// <summary>Максимальная длина окна доски, сутки (месяц с запасом).</summary>
    public const int MaxBoardDays = 62;

    private readonly ControlDbContext _context;
    private readonly IFactoryClock _factoryClock;
    private readonly IReleaseForecastService _releaseForecast;

    public PlanningController(ControlDbContext context, IFactoryClock factoryClock,
                              IReleaseForecastService releaseForecast)
    {
        _context = context;
        _factoryClock = factoryClock;
        _releaseForecast = releaseForecast;

    /// <summary>
    /// План-график цеха (PZP-07a): активные ТПА (по названию) и архивные с заданиями в окне; задания,
    /// у которых плановое окно или окно активности пересекает <c>[from, to)</c>. План, факт,
    /// прогноз и остаток буфера — <see cref="PlanningBoardCalculator"/>, не хранятся.
    /// </summary>
    [HttpGet("board")]
    [Authorize(Roles = $"{Roles.Admin},{Roles.Manager},{Roles.Observer}")]
    public async Task<ActionResult<PlanningBoardDto>> GetBoard([FromQuery] DateTime from, [FromQuery] DateTime to,
                                                               CancellationToken ct)
    {
        var fromUtc = ToUtc(from);
        var toUtc = ToUtc(to);
        if (toUtc <= fromUtc)
            return BadRequest("Конец периода должен быть позже начала");
        if ((toUtc - fromUtc).TotalDays > MaxBoardDays)
            return BadRequest($"Период не может быть длиннее {MaxBoardDays} суток");

        var now = DateTime.UtcNow;
        var schedule = await _factoryClock.GetScheduleAsync(ct);

        // План не хранится: в EF грубый отбор по плановой дате завода с запасом,
        // точный — по рассчитанному плановому окну ниже.
        var dateFrom = DateOnly.FromDateTime(schedule.ToLocal(fromUtc)).AddDays(-2);
        var dateTo = DateOnly.FromDateTime(schedule.ToLocal(toUtc)).AddDays(1);

        var byPlan = await TasksQuery()
            .Where(t => t.PlannedDate >= dateFrom && t.PlannedDate <= dateTo)
            .ToListAsync(ct);
        var byActivity = await TasksQuery()
            .Where(TaskActivityWindow.OverlapsPeriod(fromUtc, toUtc))
            .ToListAsync(ct);
        var activeIds = byActivity.Select(t => t.Id).ToHashSet();
        var candidates = byPlan.Concat(byActivity).DistinctBy(t => t.Id).ToList();

        var forecasts = await _releaseForecast.CalculateAsync(
            candidates.Where(t => t.Status == TaskStatus.InProgress).Select(t => t.Id).ToList(), now, ct);

        var items = new List<BoardTaskDto>();
        foreach (var t in candidates)
        {
            var dto = t.ToDto(schedule);
            // План уже посчитан в ToDto (TaskPlanCalculator) — собираем его обратно, без повторного расчёта.
            var plan = new TaskPlan(t.PlannedSetupMinutes * 60L, dto.PlannedReleaseSeconds,
                                    dto.PlannedReleaseBufferSeconds, dto.PlannedEndAt);
            forecasts.TryGetValue(t.Id, out var forecast);
            var timing = PlanningBoardCalculator.Build(dto.PlannedStartAt, plan,
                new BoardTaskFacts(t.Status, t.SetupStartedAt, t.StartedAt, t.CompletedAt, t.ClosedAt),
                forecast, now);

            if (!activeIds.Contains(t.Id) && !PlanningBoardCalculator.PlanOverlaps(timing.Plan, fromUtc, toUtc))
                continue;

            items.Add(new BoardTaskDto
            {
                Task = dto,
                ProductArticle = t.Mold?.ProductType?.Article,
                Plan = timing.Plan,
                Fact = timing.Fact,
                BufferRemainingSeconds = timing.BufferRemainingSeconds,
                OverdueNotStartedSeconds = timing.OverdueNotStartedSeconds,
                SetupLagSeconds = timing.SetupLagSeconds
            });
        }

        var immIdsWithTasks = items.Select(i => i.Task.ImmId).ToHashSet();
        var imms = await _context.Imms
            .Where(i => i.IsActive || immIdsWithTasks.Contains(i.Id))
            .OrderBy(i => i.Name)
            .Select(i => new BoardImmDto { Id = i.Id, Name = i.Name, IsActive = i.IsActive })
            .ToListAsync(ct);

        var byImm = items.ToLookup(i => i.Task.ImmId);
        return Ok(new PlanningBoardDto
        {
            From = fromUtc,
            To = toUtc,
            Now = now,
            Rows = imms.Select(imm => new PlanningBoardRowDto
            {
                Imm = imm,
                Tasks = byImm[imm.Id].OrderBy(i => i.Plan.SetupStart).ThenBy(i => i.Task.Id).ToList()
            }).ToList()
        });
    }

    private IQueryable<ShiftTask> TasksQuery() => _context.ShiftTasks
        .Include(t => t.Imm)
        .Include(t => t.Mold).ThenInclude(m => m.ProductType)
        .Include(t => t.Personnel)
        .Include(t => t.Order);

    // ISO с «Z» биндится как Local (уже переведённое в пояс сервера), без суффикса — Unspecified (= UTC).
    private static DateTime ToUtc(DateTime value) =>
        value.Kind == DateTimeKind.Local ? value.ToUniversalTime() : DateTime.SpecifyKind(value, DateTimeKind.Utc);
}

// План-график цеха (PZP-07a): геометрия Гантта. Время — в поясе браузера.
import { formatClock } from './shiftTimeline'

export const SCALES = ['day', 'week', 'month']
export const SCALE_LABELS = { day: 'Сутки', week: 'Неделя', month: 'Месяц' }

const ms = (v) => (v == null ? null : new Date(v).getTime())
const fmtDate = (date) => date.toLocaleDateString('ru-RU', { day: '2-digit', month: '2-digit', year: 'numeric' })

// Окно доски [from, to): сутки — от начала первой смены, неделя — с понедельника 00:00,
// месяц — с 1-го числа 00:00.
export function periodFor(scale, anchor, firstShiftStartMinutes = 0) {
  const a = new Date(anchor)
  if (scale === 'day') {
    const from = new Date(a.getFullYear(), a.getMonth(), a.getDate(), 0, firstShiftStartMinutes)
    if (from > a) from.setDate(from.getDate() - 1)
    const to = new Date(from)
    to.setDate(to.getDate() + 1)
    return { from, to }
  }
  if (scale === 'week') {
    const from = new Date(a.getFullYear(), a.getMonth(), a.getDate())
    from.setDate(from.getDate() - ((from.getDay() + 6) % 7))
    const to = new Date(from)
    to.setDate(to.getDate() + 7)
    return { from, to }
  }
  return { from: new Date(a.getFullYear(), a.getMonth(), 1), to: new Date(a.getFullYear(), a.getMonth() + 1, 1) }
}

export function stepAnchor(scale, anchor, dir) {
  const d = new Date(anchor)
  if (scale === 'day') d.setDate(d.getDate() + dir)
  else if (scale === 'week') d.setDate(d.getDate() + 7 * dir)
  else {
    d.setDate(1)
    d.setMonth(d.getMonth() + dir)
  }
  return d
}

export function periodLabel(scale, from, to) {
  if (scale === 'day') return `${fmtDate(from)} ${formatClock(from)} — ${fmtDate(to)} ${formatClock(to)}`
  if (scale === 'week') return `${fmtDate(from)} — ${fmtDate(new Date(to.getTime() - 1))}`
  return from.toLocaleDateString('ru-RU', { month: 'long', year: 'numeric' })
}

const pctOf = (t, f, total) => (t - f) / total * 100

// Вертикальная сетка: на сутках — начала смен, на неделе и месяце — границы суток.
export function gridTicks(scale, from, to, shifts = []) {
  const f = from.getTime()
  const t = to.getTime()
  const total = t - f
  const ticks = []
  if (scale === 'day') {
    const starts = [...new Set(shifts.map(s => s.startMinutes))]
    for (let day = 0; day <= 1; day++) {
      for (const minutes of starts) {
        const at = new Date(from.getFullYear(), from.getMonth(), from.getDate() + day, 0, minutes)
        if (at.getTime() >= f && at.getTime() < t) ticks.push({ at, pct: pctOf(at.getTime(), f, total), label: formatClock(at) })
      }
    }
    return ticks.sort((a, b) => a.at - b.at)
  }
  for (let at = new Date(from); at.getTime() < t; at = new Date(at.getFullYear(), at.getMonth(), at.getDate() + 1)) {
    const label = scale === 'week'
      ? at.toLocaleDateString('ru-RU', { weekday: 'short', day: '2-digit', month: '2-digit' })
      : String(at.getDate())
    ticks.push({ at, pct: pctOf(at.getTime(), f, total), label })
  }
  return ticks
}

// Интервал → позиция в процентах ширины окна; обрезается краями; пусто — null.
export function spanPct(start, end, from, to) {
  const f = from.getTime()
  const t = to.getTime()
  const s = Math.max(ms(start), f)
  const e = Math.min(ms(end), t)
  if (!(e > s)) return null
  return { leftPct: pctOf(s, f, t - f), widthPct: (e - s) / (t - f) * 100 }
}

// Цвет пары баров — по статусу задания (оттенки Element Plus).
export const GANTT_STATUS_COLORS = {
  Planned: '#909399',
  Issued: '#409eff',
  Setup: '#e6a23c',
  InProgress: '#67c23a',
  Completed: '#529b2e',
  Closed: '#a8abb2'

function seg(kind, start, end) {
  const s = ms(start)
  const e = ms(end)
  return s != null && e != null && e > s ? { kind, start: s, end: e } : null
}

// Сегменты пары: план (наладка → выпуск → буфер) и факт (наладка → выпуск до «сейчас» →
// прогноз → остаток буфера или перерасход). Нулевые сегменты отбрасываются.
export function boardSegments(item, now) {
  const n = now.getTime()
  const { plan: p, fact: f, task } = item
  const plan = [
    seg('setup', p.setupStart, p.setupEnd),
    seg('release', p.setupEnd, p.releaseEnd),
    seg('buffer', p.releaseEnd, p.bufferEnd)
  ].filter(Boolean)

  const fact = []
  if (f.setupStart) fact.push(seg('setup', f.setupStart, f.setupEnd ?? n))
  if (task.startedAt) fact.push(seg('release', task.startedAt, f.releaseEnd ?? n))
  if (f.forecastEnd) fact.push(seg('forecast', n, f.forecastEnd))
  const r = item.bufferRemainingSeconds
  if (r != null && p.bufferEnd) {
    const releaseFinish = task.status === 'InProgress' ? (f.forecastEnd ?? n) : f.releaseEnd
    fact.push(r > 0 ? seg('remaining', releaseFinish, p.bufferEnd) : seg('overrun', p.bufferEnd, releaseFinish))
  }
  return { plan, fact: fact.filter(Boolean) }
}

function pairInterval(item, now) {
  const { plan, fact } = boardSegments(item, now)
  const all = [...plan, ...fact]
  const start0 = ms(item.plan.setupStart)
  if (all.length === 0) return { start: start0, end: start0 }
  return { start: Math.min(...all.map(s => s.start)), end: Math.max(...all.map(s => s.end)) }
}

// Рамка пары в % окна и сегменты в % рамки; пара вне окна — null.
export function pairLayout(item, from, to, now) {
  const { plan, fact } = boardSegments(item, now)
  const { start, end } = pairInterval(item, now)
  const box = spanPct(start, end, from, to)
    ?? (start >= from.getTime() && start < to.getTime() ? { leftPct: spanPctPoint(start, from, to), widthPct: 0 } : null)
  if (!box) return null
  const inBox = (s) => {
    const sp = spanPct(s.start, s.end, from, to)
    if (!sp || box.widthPct === 0) return null
    return { kind: s.kind, leftPct: (sp.leftPct - box.leftPct) / box.widthPct * 100, widthPct: sp.widthPct / box.widthPct * 100 }
  }
  return { box, plan: plan.map(inBox).filter(Boolean), fact: fact.map(inBox).filter(Boolean) }
}

function spanPctPoint(t, from, to) {
  return (t - from.getTime()) / (to.getTime() - from.getTime()) * 100
}

// Дорожки пар в строке ТПА: пересекающиеся пары не накладываются друг на друга.
export function rowLanes(items, now) {
  return assignLanes(items.map(i => pairInterval(i, now)))
}

// Текстовые метки отклонений; меньше минуты не показываем.
export function boardMarks(item) {
  const marks = []
  if (item.overdueNotStartedSeconds >= 60)
    marks.push({ text: `не начато, опоздание ${formatDuration(item.overdueNotStartedSeconds * 1000)}`, row: 'plan' })
  if (item.setupLagSeconds >= 60)
    marks.push({ text: `наладка отстала на ${formatDuration(item.setupLagSeconds * 1000)}`, row: 'fact' })
  if (item.bufferRemainingSeconds <= -60)
    marks.push({ text: `перерасход ${formatDuration(-item.bufferRemainingSeconds * 1000)}`, row: 'fact' })
  return marks
}

export function planLabel(item) {
  return [item.productArticle, item.task.moldName, `${item.task.planQuantity} шт`].filter(Boolean).join(' · ')
}

const fmtStamp = (v) => {
  const date = new Date(v)
  return `${date.toLocaleDateString('ru-RU', { day: '2-digit', month: '2-digit' })} ${formatClock(date)}`
}

// Строки нативного тултипа (title) пары.
export function tooltipLines(item) {
  const { task, plan, fact } = item
  const lines = [
    `${task.immName ?? ''} · ${planLabel(item)}`,
    `Статус: ${TASK_STATUS_LABELS[task.status] ?? task.status}`,
    `Наладчик: ${task.personnelName ?? '—'}`,
    `План: ${fmtStamp(plan.setupStart)} — ${fmtStamp(plan.bufferEnd ?? plan.setupEnd)}`,
    `Норматив наладки: ${formatDuration((task.plannedSetupMinutes ?? 0) * 60_000)}`
  ]
  if (task.plannedReleaseBufferSeconds != null)
    lines.push(`Буфер выпуска: ${formatDuration(task.plannedReleaseBufferSeconds * 1000)}`)
  if (fact.setupStart) lines.push(`Начало наладки: ${fmtStamp(fact.setupStart)}`)
  if (task.startedAt) lines.push(`Начало выпуска: ${fmtStamp(task.startedAt)}`)
  if (fact.releaseEnd) lines.push(`Окончание выпуска: ${fmtStamp(fact.releaseEnd)}`)
  if (fact.forecastEnd) lines.push(`Прогноз окончания выпуска: ${fmtStamp(fact.forecastEnd)}`)
  const r = item.bufferRemainingSeconds
  if (r != null) lines.push(r >= 0 ? `Остаток буфера: ${formatDuration(r * 1000)}` : `Перерасход: ${formatDuration(-r * 1000)}`)
  for (const m of boardMarks(item)) if (!m.text.startsWith('перерасход')) lines.push(m.text)
  return lines
}

function trackHeight(row) {
  const used = lanes.value.get(row.imm.id)
  return (used.length ? Math.max(...used) + 1 : 1) * LANE_HEIGHT
