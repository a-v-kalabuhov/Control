# «Картина рабочего дня»: масштаб диаграммы и таблица статусов

- **Дата:** 2026-10-17
- **Тип:** фича (версия — минор, 0.16.0).
- **Источник:** пилот ПЗП — на диаграмме статусов не видно деталей, длительность каждого статуса
  приходится определять на глаз.

## Проблема

Диаграмма статусов в «Картине рабочего дня» (`GanttChart.vue`, ECharts) показывает смену или сутки
одним фиксированным масштабом. Короткие состояния длиной в минуты сливаются в полоски по 1 px.
Точные начало, конец и длительность есть только во всплывающей подсказке над каждым сегментом.

## Акторы и сценарии (use cases)

| Актор | Сценарий |
|---|---|
| Мастер / менеджер | Открывает отчёт за смену. Колесом мыши или ползунком приближает участок 10:00–10:30 и видит короткие простои и наладки по отдельности, подписи оси до секунд. Кнопкой «Сбросить масштаб» возвращается ко всей смене. |
| Мастер / менеджер | Переключается на вкладку «Таблица статусов». По каждому ТПА видит список состояний с началом, концом и длительностью (ч:мм:сс) и сводку часов по состояниям, совпадающую со сводной таблицей отчёта. |
| Технолог | Разбирает конкретный ТПА: сворачивает группы остальных ТПА и проверяет последовательность «Наладка → Работа → Простой» по точному времени. |

## Решение

### Компоновка `DailyReportView.vue`

Карточку «График работы ТПА» заменяет `el-tabs` с двумя вкладками:

1. **«Диаграмма»** — активна по умолчанию; содержит `GanttChart` и кнопку «Сбросить масштаб».
2. **«Таблица статусов»** — `StatusTimelineTable`.

Заголовок карточки (`ganttTitle`) остаётся. Сводная таблица по ТПА под карточкой не меняется.
При новом «Сформировать» активная вкладка сохраняется, масштаб сбрасывается.

### Масштаб — `GanttChart.vue`

- На ось X добавляется `dataZoom`: `type: 'slider'` (ползунок под осью) и `type: 'inside'`
  (колесо мыши приближает, перетаскивание сдвигает). `filterMode: 'none'`, чтобы сегменты,
  частично попавшие в окно, не пропадали.
- Минимальное окно `minValueSpan` — 1 минута.
- Формат подписей оси задаётся по уровню шага (шаблонный `axisLabel.formatter` оси времени ECharts):
  часы и минуты — `HH:mm`, секунды — `HH:mm:ss`, полночь — `HH:mm` (не дата). `minInterval` 1 ч
  убирается, иначе при приближении не появятся мелкие деления.
- Часовые markLine и границы смен остаются. При окне ≤ 1 ч часовая сетка разрежена, это допустимо.
- Компонент экспонирует `resetZoom()` (`defineExpose`). Сброс выполняется через
  `dispatchAction({ type: 'dataZoom', start: 0, end: 100 })`. При смене `data` масштаб тоже сбрасывается.
- Нижний отступ сетки увеличивается под ползунок.
- Попутно исправляется утечка: в `removeEventListener` передаётся та же функция-обработчик `resize`,
  что и в `addEventListener`.

### Таблица статусов — `StatusTimelineTable.vue` (новый, `src/components/reports/`)

Props: `data` (`immData`), `periodStart`, `periodEnd` (ISO UTC).

- `el-collapse`: одна панель на ТПА, по умолчанию все раскрыты.
- Заголовок панели: имя ТПА и сводка по ненулевым состояниям в порядке `REPORT_STATUS_KEYS`
  (цветная точка, подпись, длительность `ч:мм:сс`).
- Таблица панели (`el-table`, stripe):
  - **Состояние** — цветной маркер `REPORT_STATUS[type].hex` и подпись; неизвестный тип отображается
    как «Нет данных».
  - **Начало**, **Конец** — `HH:mm:ss` в поясе браузера (см. «Время на фронте»). Если дата
    начала/конца отличается от даты начала периода (ночная смена, сутки), к времени дописывается
    `DD.MM`.
  - **Длительность** — `ч:мм:сс` (например, `0:04:07`, `12:00:00`).
  - Если последний сегмент обрезан по «сейчас» (отчёт за текущую смену), в колонке «Конец»
    стоит «сейчас».
- У ТПА без сегментов в периоде выводится «Нет данных за период».
- Синхронизации с окном масштаба диаграммы нет: таблица всегда за весь период.

### Логика — `src/utils/statusRows.js`

`buildStatusRows(timeline, periodStart, periodEnd)` — чистая функция:

1. Обрезает каждый сегмент по `[periodStart, periodEnd)`. Сегменты нулевой и отрицательной
   длины отбрасываются.
2. Сортирует сегменты по началу и склеивает соседние сегменты одного типа без разрыва
   (`prev.end === next.start`).
3. Возвращает `[{ type, start, end, durationSeconds }]`. Длительность считается в целых секундах
   как `round((end − start)/1000)`.

`summarizeStatusRows(rows)` — сумма `durationSeconds` по типу.

`formatDuration(seconds)` — формат `ч:мм:сс`. Часы не ограничены двумя знаками.

Период таблицы — ровно смена (или сутки) без полей ±30 мин, которые показывает диаграмма.
Поэтому сводка группы совпадает с `Seconds` сводной таблицы
(`DailyStatusBreakdown.Split` по `[periodStart, min(periodEnd, now))`). Временная шкала с
бэкенда уже обрезана до «сейчас».

### Бэкенд

В `DailyReportDto` добавляются `PeriodStart` и `PeriodEnd` (`DateTime`, UTC). Значения
заполняются из `DailyReportPeriod.PeriodStart/PeriodEnd` в `ReportService`. Границы смены
считаются в поясе завода на бэкенде, фронт их не вычисляет. Миграций нет. ADR не нужен: поле в
DTO аддитивное, паттерна не задаёт.

## Вне объёма

- Таблица статусов в Excel/PDF-экспорте — при необходимости отдельной задачей.
- Фильтрация таблицы по окну масштаба диаграммы.
- Масштаб по вертикали (ось ТПА).

## Дополнение: клик по диаграмме → эпизод в таблице

**Источник:** то же обращение ПЗП, добавлено 2026-10-17 в ту же ветку и версию (0.16.0).

**Сценарий.** Мастер кликает по участку ТПА на диаграмме. Отчёт переключается на вкладку «Таблица
статусов». Группа этого ТПА раскрывается, строка эпизода подсвечивается и прокручивается в центр экрана.

- **Эпизод** — строка таблицы статусов, то есть склеенные соседние сегменты одного состояния.
- **Подсветка** — текущая строка `el-table` (`highlight-current-row`); держится до следующего клика.
  Подсветка в других группах снимается.
- **Поиск эпизода.** `findEpisodeIndex(rows, start, end)` возвращает первую строку ТПА, пересекающую
  сегмент `[start, end)`. Для сегмента, частично попавшего в поля ±30 мин, это крайняя строка периода.
  Если сегмент целиком лежит в полях вне периода, функция возвращает `-1`. Тогда вкладка не
  переключается, а пользователь видит сообщение «Эпизод вне периода отчёта».
- **`GanttChart`** — в данные серии добавляется `immId`. Клик по сегменту генерирует событие
  `segment-click` с полями `{ immId, start, end }` (мс). У сегментов курсор-рука, в подсказке строка
  «Клик — показать в таблице».
- **`StatusTimelineTable`** — `defineExpose({ focusEpisode(immId, start, end) → Promise<boolean> })`.
- **`DailyReportView`** — сначала проверяет эпизод через `findEpisodeIndex` и `buildStatusRows`: панель
  таблицы ленивая, до первого показа её нет. Затем переключает вкладку и после монтирования вызывает
  `focusEpisode`.
- **Тесты (Vitest):**
  - `findEpisodeIndex`;
  - событие клика в `GanttChart`;
  - `focusEpisode`: раскрытие группы, `current-row`, `scrollIntoView`;
  - `DailyReportView`: переключение вкладки и подсветка строки; сегмент вне периода оставляет вкладку
    «Диаграмма».
- **Руководство менеджера, §8.1** — одна фраза про клик по диаграмме.
